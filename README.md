# DSH Local Skills Library

The VoltAgent Awesome Agent Skills directory plus `danjdewhurst/story-skills`, downloaded onto disk and exposed through DSH's public `ctx.skills.registerProvider` and `ctx.tools.register` hooks. No Harness source changes are required.

Install this plugin as a local path with DSH Plugins. Run `npm run library:download` from the plugin directory to download the catalog's publicly accessible GitHub repositories and the complete Story Skills package. This explicit maintenance command never runs repository setup scripts, package lifecycle hooks, or downloaded instructions. Completed snapshots are reused. `--repo owner/repository` restricts a download pass while retaining other existing snapshots.

The default library is `$DSH_HOME/dsh-voltagent-skills/library`, or `~/.dsh/dsh-voltagent-skills/library`. Set plugin `libraryDir` to move it. Complete repository snapshots preserve relative scripts, references, templates, and licenses. `manifest.json` records installed skills, original source URLs, archive hashes, and unresolved catalog entries. `download-status.json` records download progress. Snapshots are bounded to 512 MiB compressed / 2 GiB expanded. Verified directory-to-repository mappings live in `data/source-repositories.json`; directory URLs are not assumed to be repository names. Unavailable, oversized, gated, or non-GitHub entries are reported explicitly, never silently advertised as working tools.

Discovery and loading use local files only: **no runtime downloads or fallback HTTP calls**. Collection repositories are expanded into individual `SKILL.md` files. `voltagent_skills` searches the downloaded library and returns exact names for DSH's standard `skill` tool. Manifest changes invalidate the registry through public provider control. Unloading the plugin removes registrations and its manifest watcher while retaining files.

The public `agent/pre-step` hook bounds this plugin's model-facing catalog to 24 relevant summaries (12,000 characters maximum). The complete registry stays searchable and exact-name loads still work; other providers' entries and DSH's catalog identity are preserved. This prevents selecting the stock skill loader from inserting thousands of summaries into the model's context. `python3 scripts/download-library.py --index-only` rebuilds the manifest without any network calls.

Story Skills includes all 24 workflows and its companion Node CLI. Loaded Story Skills include the exact local CLI path. Use the ordinary workspace-authorized shell tool; no `npx` download is needed. Instructions grant no extra permissions. A skill referring to a cloud service still requires that service; downloading guidance does not make an external API local or install arbitrary model weights/dependencies.

Upstream copyrights and licenses remain with each source. The VoltAgent snapshot and license are in `data/`. `npm run catalog:update` refreshes metadata explicitly; rerun the downloader to materialize new sources. This plugin does not publish changes to GitHub.
